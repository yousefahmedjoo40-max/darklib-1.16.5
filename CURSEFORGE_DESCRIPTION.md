# Darklib
A dark-night library for **Forge 1.16.5**.

- Brutally dark nights: heavy black fog and a very short view distance
- Daytime is untouched
- Smooth dusk and dawn transitions
- Caves and interiors unaffected; Night Vision helps
- Configurable
- API for other mods: `DarklibAPI.getNightFactor(world)`

**Requires:** Minecraft 1.16.5 + Forge 36.2.0+
